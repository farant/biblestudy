# Bible Study

A simple website for our Bible study group, hosted on GitHub Pages.

## How This Site Works

This site is made of two files:

- **`index.html`** — Your homepage content (text, headings, links, etc.)
- **`style.css`** — The visual styling (colors, fonts, spacing, etc.)

When you edit these files and push the changes to GitHub, your website updates automatically.

## How to Edit Your Site

1. Open `index.html` in GitHub (click on the file, then click the pencil icon to edit)
2. Change any of the text between the HTML tags
3. Click "Commit changes" to save

The file has comments (lines starting with `<!--`) explaining what each section does.

## Your Site URL

Once GitHub Pages is enabled, your site will be available at:

**`https://farant.github.io/biblestudy/`**

## Enabling GitHub Pages

If not already enabled:

1. Go to your repository on GitHub
2. Click **Settings** (the gear icon)
3. Scroll down to **Pages** in the left sidebar
4. Under "Source", select the branch your site is on (e.g., `main`)
5. Click **Save**
6. Wait a minute or two, then visit your URL above
